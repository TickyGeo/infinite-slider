Infinite slider
A slider in which emblemes of famous football clubs move infinit. You can stop them if put the cursor on them.
I used HTML, JS and CSS for this project. The slider can move infinite thanks to CSS. With @keyframes animation. And can stop thanks to :hover. I used JS to duplicate the slider. So it can be really infinite now. If I wouldn't duplicate the div which contains the ebmlems we'd have to wait till the current slide finish to start another one from the beginning. But thanks to duplication it works infinite. I could not do it with JS, just duplicate it mechanically in HTML, but it would make the code "dirty" and slow. So I wanted to show how I can work with JS in this small but reasonable project.
